# Corpus scoring

These scripts turn ontology metrics into a score for selecting continual pretraining (CPT) data. Run them in the order below: identify redundant metrics, remove them from the random datasets, estimate their association with downstream F1, and score individual corpus files.

## Requirements

Python 3.10+ and:

```bash
python3 -m pip install numpy pandas openpyxl scipy
```

Inputs are Excel workbooks with one row per ontology or fragment in `DetalleOntologías`, numeric metric columns, and token counts in `NumTokensLlama32_3B`. The random datasets also need their downstream F1 results at epochs 1 and 2.

## Workflow

| Step | Script | Role and connection to the next step |
| --- | --- | --- |
| 1 | [identify_redundant_metrics.py](identify_redundant_metrics.py) | Analyze the full corpus workbook. Exclude constant or empty metrics and iteratively remove redundancy where absolute Pearson correlation exceeds the threshold. Produce `columnas_eliminadas.txt` and `metricas_seleccionadas.xlsx`. F1 is not used. |
| 2 | [remove_redundant_metrics.py](remove_redundant_metrics.py) | Apply the removal list from step 1 to every random-dataset workbook, creating copies with a common set of remaining metrics. |
| 3 | [compute_metric_f1_associations.py](compute_metric_f1_associations.py) | Compute token-weighted metric means for each cleaned random dataset and correlate them with F1 using Pearson and Spearman at both epochs. Retain metrics whose four coefficients are finite, nonzero, and share a sign. Their mean absolute coefficient becomes `Association_score`. P-values are reported, without filtering. |
| 4 | [score_corpus_files.py](score_corpus_files.py) | Combine the full corpus metrics retained in step 1 with the associations from step 3. Min-max normalize suitable metrics, invert negatively associated ones, and compute their weighted mean as `association_correlation_score`. Higher scores indicate files favored by the learned criterion. |

## Example execution

Run from this directory, replacing the example input locations:

```bash
# 1. Preserve token counts as metadata rather than treating them as a metric.
python3 identify_redundant_metrics.py full_corpus.xlsx \
  --output-dir redundancy --threshold 0.85 \
  --metadata Dominio Ontología Archivo RutaRelativa NumTokensLlama32_3B

# 2. Apply the same removal list to all random datasets.
python3 remove_redundant_metrics.py \
  --input-dir randoms \
  --metrics-txt redundancy/columnas_eliminadas.txt \
  --output-dir randoms_clean

# 3. Learn associations from dataset metrics and measured F1 scores.
python3 compute_metric_f1_associations.py randoms_clean \
  --pattern '*random*.xlsx' --scores f1_scores.csv \
  --output metric_f1_associations.xlsx

# 4. Score each file in the full corpus.
python3 score_corpus_files.py \
  --dataset redundancy/metricas_seleccionadas.xlsx \
  --correlations metric_f1_associations.xlsx \
  --output scored_corpus.xlsx
```

Random workbook names must contain `random` immediately followed by a number, such as `random1.xlsx`. The scores file must contain `dataset,F1_e1,F1_e2`, with matching dataset numbers. If `--scores` is omitted, step 3 uses the experiment scores embedded in the script.

Step 4 reads the `Todas` and `Aptas` sheets generated by step 3. It assigns constant metrics a neutral normalized value of `0.5` and appends normalized, oriented, and weighted contributions alongside the final score.
